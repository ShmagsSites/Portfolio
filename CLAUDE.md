# Web Design Instructions

You are helping build premium, modern websites.

## Tech Stack
Use:
- Next.js
- React
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide Icons

## Design Style
Always make websites:
- modern
- clean
- mobile-first
- responsive
- premium looking
- conversion-focused
- not generic AI-looking

Use strong spacing, typography, hover effects, shadows, rounded cards, subtle animations, and clear CTA buttons.

## Required Sections for Business Sites
For landing pages, usually include:
- Navbar
- Hero section
- Trust badges
- Services/features
- Why choose us
- Testimonials
- FAQ
- Contact form
- Footer

## Quality Rules
Before finishing:
- Check mobile layout
- Check desktop layout
- Check accessibility
- Check SEO metadata
- Check broken buttons/links
- Check spacing and consistency
- Fix any obvious issues
